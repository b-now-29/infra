집관 개인정보처리방침

시행일: 2026년 11월 17일

집관은 축구 생중계를 보는 관중이 같은 경기의 가상 경기장에 모여, 같은 진영 관중과 채팅으로 응원하는 Chrome 확장 프로그램입니다. 이 방침은 집관이 어떤 정보를 다루고, 어떻게 쓰고, 무엇을 남기지 않는지 설명합니다.

1. 다루는 정보

  • 채팅 내용: 입력한 채팅은 서버를 거쳐 같은 경기장의 같은 진영 관중에게 전달됩니다. 서버는 채팅 내용을 전달만 하고 저장하지 않습니다.
  • 고른 진영: 경기마다 고른 진영(홈·원정)은 다음 입장 때 다시 고르지 않도록 이용자의 브라우저에만 저장합니다. 전체 화면 안내를 이미 봤는지도 브라우저에만 저장합니다. 서버에 따로 보관하지 않습니다.
  • 보고 있는 중계 페이지 주소: 지원 사이트의 영상 페이지에서 어떤 경기인지 찾기 위해 그 페이지 주소를 서버에 보냅니다. 서버는 등록된 경기와 비교하는 데만 쓰고 저장하지 않습니다.

집관은 이름, 이메일, 계정 정보, 위치 정보를 수집하지 않으며, 로그인이 없습니다.

2. 서버에 남는 기록

서비스 운영을 위해 서버에는 경기별·진영별 숫자만 남깁니다.

  • 입장 수
  • 머문 시간(평균)
  • 채팅 개수(일정 간격마다, 가장 많았던 1초의 개수 포함)
  • 관중 수

이 기록에는 채팅 내용이나 개인을 알아볼 수 있는 정보가 들어가지 않습니다.

3. 이용 목적

  • 같은 경기장의 같은 진영 관중에게 채팅을 전달하기 위해
  • 보고 있는 중계가 어떤 경기인지 찾기 위해
  • 서비스 이용 규모를 파악해 개선하기 위해(위의 숫자 기록)

4. 제3자 제공

위 1항의 채팅 전달 외에는 어떤 정보도 제3자와 공유하거나 판매하지 않습니다. 광고, 신용 평가, 대출 등의 목적으로 사용하지 않습니다.

5. 전송 보안

확장 프로그램과 서버 사이의 모든 통신은 암호화된 연결(wss://, HTTPS)로 이루어집니다.

6. Chrome 웹스토어 사용자 데이터 정책 준수

집관이 다루는 사용자 데이터의 사용과 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Chrome 웹스토어 사용자 데이터 정책을 준수합니다.

7. 정보 삭제

브라우저에 저장된 진영 정보는 확장 프로그램을 삭제하면 함께 지워집니다. 서버에는 개인을 알아볼 수 있는 정보가 남지 않으므로 따로 삭제할 정보가 없습니다.

8. 방침 변경

이 방침을 바꾸면 이 페이지에 바뀐 내용과 시행일을 고쳐 알립니다.
